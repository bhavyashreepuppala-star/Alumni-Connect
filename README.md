# Alumni Connect

### Professional Alumni Networking Platform

Alumni Connect is a networking platform designed to connect current college students with alumni and college administration.

### Key Features
- Student, Alumni and Admin accounts
- Professional alumni profiles
- Alumni verification
- Networking and mentorship
- Job and internship opportunities
- Events and webinars
- Community discussions
- LinkedIn integration

### Technology Stack
- Frontend: React, Vite, TypeScript, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MySQL
- ORM: Prisma
- Version Control: Git and GitHub
